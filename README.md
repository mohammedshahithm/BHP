### Bengaluru House Price Prediction | Machine Learning, Flask, JavaScript
- Developed a machine learning application to estimate Bengaluru residential property prices based on location, square footage, BHK, and bathroom count.
- Trained and integrated a Scikit-learn regression model with a Flask REST API to generate price predictions from user inputs.
- Built a web interface using HTML, CSS, and JavaScript, enabling users to select property details and view estimated prices.
- Deployed the frontend and backend on Render and published a live demo.

**Tech Stack:** Python, Pandas, NumPy, Scikit-learn, Flask, Gunicorn, HTML, CSS, JavaScript, Git, GitHub, Render.
